# Quora Clone - Q&A Web Application

A full-stack RESTful Web Application built with Node.js, Express, and EJS. This platform allows users to post questions, share detailed answers, upload images, and manage posts with complete CRUD (Create, Read, Update, Delete) functionality.

## Features
- **Quora-style UI**: Dedicated Question and Answer card structures.
- **Full CRUD Operations**: Create new Q&A posts, read feed, edit existing posts, and delete posts.
- **Image Uploads**: Integrated `Multer` middleware for uploading and handling dynamic file uploads.
- **RESTful Routing**: Clean URL structure using `method-override` for `PATCH` and `DELETE` requests.
- **Custom UI Design**: Custom CSS card layouts.

## Tech Stack
- **Backend**: Node.js, Express.js
- **Templating Engine**: EJS (Embedded JavaScript)
- **Middleware & Tools**: Multer (File Uploads), UUID (Unique IDs), Method-Override
- **Frontend**: HTML5, CSS3
